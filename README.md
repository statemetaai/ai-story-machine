# 📖 亲子 AI 故事机 · AI Story Machine

给孩子的睡前故事机：选主角、选地方、选一个小道理，点一下就能编一个新故事，还能读出来。

这是 Max 的第一个 GitHub 项目，也是 AIoT 方向的起点：**先在网页上验证玩法，再搬到 ESP32-S3 硬件上**，按按钮就能听故事。

## ✨ 网页版现在就能玩

打开 `index.html`，或者访问 GitHub Pages 在线演示：

👉 https://statemetaai.github.io/ai-story-machine/

玩法：

1. 填小朋友的名字、选年龄段（3–5 / 6–8 / 9 岁以上）
2. 选主角：小猫咪咪、 小恐龙嘟嘟、 小宇航员星星、 小鹈鹕皮皮、 小老鼠吱吱
3. 选地方：森林、太空、海底、湖边、彩虹小镇
4. 选小道理：勇敢、分享、好奇、坚持、友爱
5. 点 **“编一个新故事”**，也可以点 **“随便来一个”**
6. 点 **“读给我听”**，浏览器会用中文语音读出来；喜欢就点 ⭐ 收藏

网页版故事是本地模板组合生成的，不用联网、不用填 API Key，适合先验证玩法、调故事风格。

## 🗺️ 路线图

### 第 1 步：网页版验证（现在这一步 ✅）
- [x] 选主角 / 场景 / 道理，生成故事
- [x] 朗读、收藏、随机故事
- [x] GitHub Pages 在线演示

### 第 2 步：ESP32-S3 硬件版
- ESP32-S3 开发板 + I2S 功放 + 喇叭 + 麦克风
- 几个按钮 / 旋钮选主角和场景，替代网页上的点选
- 联网调用 AI 生成故事 + 语音合成，断网时用本地模板故事兜底
- 电池供电，放床头就能用

### 第 3 步：越做越好
- 孩子说一句话，AI 接着编下去（语音输入 → 故事续写）
- 故事库、收藏同步
- 家长端：故事时长、主题控制

## 🛠️ 本地运行

```bash
# 直接双击打开 index.html 就能玩
# 或者用本地服务器：
python3 -m http.server 8000
# 打开 http://localhost:8000
```

## 💡 为什么先做网页版？

硬件要花钱、要等快递、要调接线。先把“娃喜不喜欢、故事好不好听、操作顺不顺”在网页上验证清楚，再上硬件，少走弯路。
